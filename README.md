# 🌐 Portfólio Web Responsivo

Este projeto é um site de portfólio pessoal desenvolvido com foco em apresentação profissional e experiência do usuário.

O projeto foi inicialmente baseado em um modelo existente, mas foi totalmente adaptado, personalizado e melhorado para refletir meu estilo e minhas habilidades como desenvolvedor.

---

## 🚀 Tecnologias utilizadas

* HTML
* CSS
* JavaScript

---

## ✨ Melhorias implementadas

* Design adaptado ao meu estilo pessoal
* Layout totalmente responsivo (mobile, tablet e desktop)
* Melhor organização do código
* Ajustes na estrutura e na interface do usuário

---

## 📱 Responsividade

O projeto foi desenvolvido com foco em responsividade, garantindo uma boa experiência em diferentes dispositivos e tamanhos de tela.

---

## 🎯 Objetivo

Este projeto foi criado com o objetivo de apresentar minhas habilidades como desenvolvedor web e servir como portfólio para oportunidades profissionais e freelas.

---

## ⚠️ Observação

Este projeto foi baseado em um modelo encontrado na internet e posteriormente adaptado e melhorado por mim, incluindo personalização visual e ajustes funcionais.
